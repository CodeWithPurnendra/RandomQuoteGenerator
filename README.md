# ✨ Random Quote Generator (React)

A beautiful and minimal **Random Quote Generator** built using **React**.  
It fetches inspirational quotes from an API and displays them in a modern glassmorphism UI with smooth animations and icons.

---

## 🚀 Features

- 🎯 Fetches random quotes from an API
- 🔄 Generate a new quote with one click
- 🧾 Quote & refresh icons using `react-icons`
- 🎨 Glassmorphism UI with gradient background
- ✨ Smooth hover & loading animations
- 📱 Fully responsive design

---

## 🛠️ Tech Stack

- **React (Hooks)**
- **CSS3**
- **JavaScript (ES6+)**
- **react-icons**
- **Dummy API**

---
## 📦 Installation & Setup

### Clone the repository
```bash
git clone https://github.com/CodeWithPurnendra/RandomQuoteGenerator.git 
```
### Navigate to the project folder
```bash
cd random-quote-generator
```
### Install dependencies
```bash
npm install
```
### Start the development server
```bash
npm run dev
```
